## Différencier les interventions
- **Proposition** : le Conseil suggère une architecture, un libellé, une règle.
- **Validation de doctrine** : le promoteur ratifie le principe, pas nécessairement son implémentation.
- **GO DIAGNOSTIC** : permission limitée à l'étude et aux lectures autorisées.
- **GO BUILD** : permission explicite de modifier l'application, avec périmètre délimité.
- **Implémentation** : commits/DB modifiés ; ne prouve pas la recette.
- **Recette** : vérification factuelle, réserve documentée.
- **Déploiement** : attestation indépendante que la version correspondante est réellement en ligne.
