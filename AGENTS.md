
- eBilling environment is chosen only by EBILLING_ENV (lab default); production needs full config plus host allowlists (EBILLING_PROD_ALLOWED_*_HOSTS) — prevents accidental real payments.
- Gesture prices: system_settings (candle_price/flower_price) is the only writable source, edited via the audited admin-settings function; ritual_prices is a DB-trigger mirror read by billing — keeps one price grid with audit trail.

- Payment cron jobs: expiry runs in-DB (`expire_orphan_stale_transactions`, orphans without bill_id only); reconciliation worker requires vault-held `x-cron-token` or service-role key — no anon key in cron, no public trigger.
- RAGet corpus: `rag_chunks` is a derived index rebuilt per memorial by `rag_reindex_memorial` via triggers; read only through admin-gated `rag_hybrid_search` (RRF of FTS/trigram/vector) — visibility is rechecked at query time, and embeddings come only from local CPU multilingual-e5-small (passage:/query: prefixes, L2-normalized) written via admin-only `rag_set_embeddings` with content md5 check; vector branch keeps cosine distance <= 0.185; no external AI.
- The editorial moderation experiment in migrations 0035/0036 is inactive and deprecated; publication and Voir+ retain their pre-audit rules because this request was a status report, not implementation authorization.
- Post-publication reports use guestbook_reports and admin-only transactional RPC decisions; editorial_hidden is independent of is_hidden, and every public guestbook read must exclude editorial_hidden and deleted_at — payment fulfillment must never undo editorial decisions.
- Contributor portraits are resolved by account UUID through a batched `profiles_public` read shared by tributes, maillage, lineage and its prefetch; current public account photos take priority over snapshots and demo portraits, without exposing private profile fields.
- Person photographs use Photo with contain and reserved parent dimensions; browser preparation of new uploads uses preparePhotoUpload, never historic storage rewrites — preserves source integrity and avoids duplicate implementations.
- Back-office relational explanations use explicitly selected UUID-keyed server context candidates, public/RLS-filtered endpoints and original accepted relation IDs; AI prose is never treated as a canonical citation — prevents name joins and invented provenance.
- Obituary price waivers come only from the audited `obituary_free_campaign` setting evaluated server-side in create-memorial/ebilling; the legacy is_monetized switch governs only written tributes without gestures — candles/flowers are always billed so no free path can grant gestures or Voir+.
- Memorial geography (GEO-01): three declared lands stored as ISO alpha-2 + free locality on memorials, never inferred; changes audited by DB trigger, names/flags resolved locally (Intl + bundled SVG) — no external geo API.
- Gesture quota: system_settings gesture_max_per_tribute (missing = 1, bounds 1–10) is enforced server-side in publish-tribute and ebilling via _shared/gestureRules.ts before any operator call; the UI only mirrors it — prevents bypass by direct calls.
